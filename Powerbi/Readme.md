# Power BI Dashboards

This folder contains the Power BI dashboard screenshots created from the Gold-layer tables.

## Dashboards

The reporting layer includes:

- Executive Overview
- Sales Analysis
- Product Performance
- Customer RFM Segmentation
- Returns Analysis
- Customer Cohort Retention

## Data Source

Power BI connects to the Databricks SQL Warehouse and reads the business-ready Gold tables.

Dashboard screenshots are available inside the `screenshots/` folder.

# Azure Databricks

This folder contains the Databricks notebooks used to transform Bronze data into cleaned Silver tables and business-ready Gold tables.


## Folder Structure

- `silver/` — Data cleaning, CDC processing, deduplication and SCD Type 2 logic.
- - `gold/` — Business-level analytical tables used for reporting and Power BI
 
  - ## Technologies Used

- Azure Databricks
- PySpark
- Delta Lake
- Unity Catalog
